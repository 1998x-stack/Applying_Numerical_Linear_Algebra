COURSE GUIDE

从结构到误差：如何使用这套数值线性代数课程

本课程以实际数学问题为起点，依次解释输入结构、条件数、分解算法、浮点数值误差和运行性能。现有 56 篇深度重构文章，分布于第一章、第二章、第三章和第六章；另外的原始章节仍保留历史路径，尚待同标准逐篇深审。

三条理解路线

先理解数值计算：从第一章的矩阵、扰动和舍入误差开始，建立残差与真实前向误差的区别。再理解线性系统：读第二章的 GEPP、Cholesky、迭代改进、分块和带状/稀疏结构。最后理解近似模型：第三章从投影出发，比较正规方程、QR、SVD 与最小二乘敏感性。

第二章到第三章的连续八篇

以下每篇都可以独立阅读；数值图允许调整参数，但“演示模型”不等于硬件 benchmark。数学论证及反例均配有对应的 Python 与 MATLAB 示例。

如何独立验证

在仓库根目录安装 requirements-dev.txt，再运行 python -m unittest discover -s tests -v、python scripts/validate_site.py 和 python scripts/browser_qa.py。最后一项需要先安装 Chromium 的 Playwright 环境；自动检查覆盖桌面、平板、手机以及公式和参数交互。

MATLAB 对照稿包含必要断言，但没有实际 MATLAB 环境运行报告时只能标注为“待运行”。数学模型中的条件数和图形是计算例子，不等同于实验测得的性能。

来源和再分发边界

主线参考 James W. Demmel《Applied Numerical Linear Algebra》（SIAM，1997）；独立文章还附有 NumPy、SciPy 和 LAPACK 等实现文档。教程正文与图形独立编写，不复制原著图片。仓库原有 PDF 的再分发许可尚未独立核验；Pages 构建不公开 PDF 或原始可执行脚本。
