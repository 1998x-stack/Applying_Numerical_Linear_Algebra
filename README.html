PROJECT GUIDE

项目说明

本课程围绕数值线性代数中的标准问题、矩阵分解、条件数、舍入误差、算法稳定性和高性能计算展开。第一批八篇文章已建立独立叙事、原创图解、数学公式和交互演示。

如何阅读

从 课程首页 选择主题。每篇文章都可以独立阅读；页面底部列出延伸资料，代码示例保存在 GitHub 源仓库。

如何验证

本地运行 python -m unittest discover -s tests -v 和 python scripts/validate_site.py。浏览器验收需要安装 Playwright 与 Chromium。MATLAB 脚本需要 MATLAB 或兼容环境，不会把 Python 测试通过等同于 MATLAB 实测。

来源与版权

课程结构参考 James W. Demmel, Applied Numerical Linear Algebra, SIAM, 1997。正文和图示独立编写。仓库已有原始 PDF 的再分发许可尚未独立核验；Pages 构建不会发布 PDF、Python 或 MATLAB 文件。
