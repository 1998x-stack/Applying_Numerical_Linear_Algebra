## 发现并修正的知识问题

- 带主元 LU 使用 PA=LU；说明无置换的 A=LU 需要额外条件。
- SVD 的奇异值是 A*A 特征值的非负平方根，不把两者混为一谈。
- 条件数定义按指定范数给出；矩阵扰动界说明分母条件。
- 区分 unit roundoff 和 binary64 的 machine epsilon。
- 不把 O(nu) 当作任意算法的通用舍入误差界。
- 区分理论 FLOPs、算术强度和实测运行时间。
- 多项式条件数按降幂系数的真实幂次计算；二分法显式验证括区间。
