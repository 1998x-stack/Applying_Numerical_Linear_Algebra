# 3.4.3 正交变换的舍入误差：为何数值稳定不等于绝对精确

正交矩阵的 2-范数条件数恒为 1，但实际计算使用浮点数。稳定 QR 的关键，是可把每一步误差解释为小扰动，并通过正交性缺陷与重构残差进行可复核检查。

## 为什么这个方法存在？

解析数学中 HᵀH=I、GᵀG=I，似乎乘上这些矩阵不会出错；但 IEEE 浮点数只能近似表示 c、s 或 Householder 向量。执行上千次正交变换后的矩阵 Q̂ 一般不可能精确满足 Q̂ᵀQ̂=I。如果它偏离了单位矩阵，怎样判断是正常的舍入效应，还是算法本身失去了稳定性？

## 原理：从矩阵结构到可执行步骤

对精确正交 Q，||Qx||₂=||x||₂、||Q||₂=1、κ₂(Q)=1。在浮点中，评价计算出的 QR 至少需要两项：正交性缺陷 η_Q=||Q̂ᵀQ̂−I||₂，以及相对重构残差 η_A=||A−Q̂R̂||_F/||A||_F。Householder 反射通常通过稳定的内积与尺度处理得到很小的缺陷；经典 Gram–Schmidt 在近共线列时可能失去正交性。单凭 η_A 小不能保证 Q̂ 的列正交；单凭 η_Q 小也不能保证分解能正确重构 A，所以必须两者同时审计。更严格的后向稳定分析要求陈述运算模型、维度、unit roundoff 和误差常数，不能把“总是 O(u)”当成对任意病态输入的无条件精度保证。

\[
\eta_Q=\|\hat Q^\top\hat Q-I\|_2,\quad \eta_A=\frac{\|A-\hat Q\hat R\|_F}{\|A\|_F}
\]

数学过程拆成四个自足的判断：

1. **解析正交 QᵀQ=I**：明确输入形状、关键假设和要修改的几何量。

2. **浮点计算 Q̂,R̂**：建立局部变换，保持必要的正交或秩结构。

3. **测量 η_Q 正交缺陷**：推导新变量、零元素或被保留的奇异模态。

4. **测量 η_A 重构残差**：用矩阵恒等式、正交性或真实残差验证。

## 手算与可复现的小矩阵

取 A=[1, 1+εt]∈R⁴ˣ²，t=(0,1,2,3)ᵀ、ε=10⁻⁸，列几乎平行。使用 NumPy 的 QR（由底层 LAPACK 稳定例程实现）得到 Q、R，计算 η_Q 与 η_A，并验证它们在这个小型可重复例子中都很小。可另外自行实现一次经典 Gram–Schmidt 作为课堂对照，但若没有固定浮点平台，不能断言不同环境中的正交缺陷必然严格大小排序。

## 适用条件、舍入与失败情形

η_Q 与 η_A 的阈值不是跨规模、跨精度都固定的常数；m、n、范数、运算顺序与浮点环境均影响可接受误差。QR 分解的后向稳定性不改变最小二乘问题本身的条件数：即使 Q̂ 和 R̂ 很准确，病态问题的解也可能对 b 敏感。直接对 AᵀA 求特征向量再归一化，不能作为数值稳定的 QR 替代方案。

## 结论

稳定正交算法的可验证核心，是分解能正确重构输入且正交性缺陷足够小；误差必须从计算结果测量，而不是靠“正交”这个名字保证。
