3.5.1 秩亏最小二乘的 SVD 解：最小范数与截断奇异值

当 A 有零奇异值，最小二乘参数不唯一；伪逆从所有最优拟合中选出最小范数解。当最小奇异值虽非零却极小时，截断奇异值还可限制噪声放大，但会牺牲部分拟合精度。

为什么这个方法存在？

若 A∈Rᵐˣⁿ 的 rank r<n，则存在非零 z 使 Az=0，因此若 x* 是最小二乘解，那么 x*+z 给出同样的拟合残差；参数没有唯一值。更严重的是，如果 σ_min(A) 非零但非常小，在这个方向上除以 σ_min 会把观测的细小噪声放大。我们需要区分“精确秩亏的最小范数选择”和“近秩亏时故意丢弃不可靠的方向”两种操作。

原理：从矩阵结构到可执行步骤

写 A=UΣVᵀ，非零奇异值 σ₁≥…≥σ_r>0。Moore–Penrose 解 x⁺=Σ_{j≤r} v_j(u_jᵀb/σ_j)，满足最小残差并与 null(A) 正交，因此在所有最小二乘解中范数最小。若自定义阈值 τ>0，截断 SVD (TSVD) 只保留 σ_j>τ 的模态：x_τ=Σ_{σ_j>τ} v_j(u_jᵀb/σ_j)，它相当于求解一个低秩近似矩阵 A_τ 的最小二乘问题。阈值需要相对矩阵尺度、观测噪声和建模目标指定；NumPy/SciPy 的自动数值秩阈值并不代表确定的物理噪声边界。

适用条件、舍入与失败情形

TSVD 不能自动区分测量噪声与真实信号；选 τ 太大可能丢失重要方向，选太小会放大噪声。该案例存在精确 0 奇异值，计算中浮点 SVD 的极小非零值需要容差判断；还要区分 rank(A) 与软件推断的 numerical rank。含约束、稀疏超大矩阵或结构化正则化的场景，未必适合直接形成完整稠密 SVD。

结论

SVD 把参数不可辨识性和噪声放大写成可观察的奇异值，伪逆解决非唯一性，截断则引入明确的拟合精度—参数范数权衡。
