# 6.5.4 慢模态从何而来：Jacobi、GS 与 SOR 的收敛速度

同样一次扫描，为什么一个方法可能需要 N² 级别的轮次，另一个只需要 N 级别？答案不在于每轮的乘法数量，而在于迭代矩阵对低频误差模态的压缩程度。

## 一个具体的求解难题

考虑 N 个内部点的一维 Dirichlet Poisson 模型 T_N=tridiag(−1,2,−1)。它是对称正定的，但当 N 增大，最慢的正弦误差模态会越来越难被简单的局部更新消除。把误差写成 e^(k+1)=B e^(k)，迭代能否收敛取决于 B 的谱半径，而渐近收敛快慢通常被绝对值最大的特征值控制。

## 从数学定义拆开每一步

Jacobi 的迭代矩阵为 B_J=I−(1/2)T_N，其正弦特征向量 v_j(i)=sin(ijπ/(N+1)) 对应特征值 cos(jπ/(N+1))，所以 ρ(B_J)=cos(π/(N+1))。在本模型一致排序下，Gauss–Seidel 的谱半径是 ρ(B_GS)=ρ(B_J)²。渐近展开 cos(π/(N+1))≈1−π²/[2(N+1)²]，因此降低一个固定比例的最慢误差通常需要 O(N²) 次 Jacobi/GS 扫描，而每轮需 O(N) 工作量。二维 N×N 网格将未知量总数改为 n=N²，不能把 N 与 n 混用。

\[
\rho(B_{GS})=\rho(B_J)^2=\cos^2\!\left(\frac{\pi}{N+1}\right)
\]

公式说明：ρ(B_GS) = ρ(B_J)²，ρ(B_J)=cos(π/(N+1))。本页所有模型结论均以给定的矩阵结构与假设为前提。

## 数据流逐步解释

1. **正弦误差模态**：明确上一轮计算状态及问题条件。

2. **Jacobi 缩放**：对局部量或子空间执行本步确定性变换。

3. **GS 平方谱因子**：依据公式组合各项并保留边界条件。

4. **SOR 调整 ω**：输出可在实验中核查的新状态或界。

从 Poisson 的正弦特征模态，经过 Jacobi 谱因子和 GS 的平方关系，再到 SOR 的参数选择；各结论均限于所述模型。

## 可手算的小例子

在同一类模型的适用排序下，SOR 的最优参数为 ω*=2/[1+sin(π/(N+1))]，相应渐近收敛因子更接近 1−O(1/N) 而非 1−O(1/N²)。这解释了为何调参能显著改善慢模态，但也说明它仍不是多重网格那种跨尺度误差校正。例 N=16 时，Jacobi 模型谱半径为 cos(π/17)，Gauss–Seidel 为其平方，SOR 的最优模型因子为 ω*−1；这些量均为理论计算值，并非真实机器的计时结果。

## 适用边界与失败模式

这些特征值与最优参数结论建立在规则 Poisson 模型、零 Dirichlet 边界和适用的扫描排序之上。改变系数、网格、边界条件或排列会改变迭代矩阵。谱半径表征渐近速度，也不能等同于任意初始误差在每一轮都按同一比率衰减；非正规矩阵还可能出现暂时增长。

## 一句话总结

先找到误差的慢模态，才能理解迭代收敛为何会随网格细化恶化；阶数比较必须标明 N 与总未知量 n 的关系。
