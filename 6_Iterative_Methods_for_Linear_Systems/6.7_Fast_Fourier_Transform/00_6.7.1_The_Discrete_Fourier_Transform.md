# 6.7.1 DFT：把离散信号拆成互相正交的旋转模态

时域的加减、移位和邻接关系，在 Fourier 基底下会变成更简单的频率系数。理解 DFT 的归一化和复指数方向，才能正确读懂 FFT 与谱求解器。

## 先看问题：为什么会需要它？

取长度 N 的复数向量 x=(x₀,…,x_{N−1})ᵀ。对周期性信号，若直接逐点操作，卷积和许多平移不变算子都有跨位置耦合。DFT 改用 N 个复指数基，问“每个频率在信号中占了多少？”要先固定正变换的指数符号与反变换的 1/N 因子，否则频谱和卷积的公式会差上一个常数。

## 把公式分解成具体操作

定义 ω=exp(−2πi/N)，X_j=Σ_{k=0}^{N−1}x_k ω^{jk}，j=0,…,N−1。逆变换 x_k=(1/N)Σ_j X_j exp(+2πijk/N)。若 F 的第 (j,k) 项是 ω^{jk}，则 F*F=NI，因此 (1/√N)F 才是酉矩阵；在 NumPy 默认 norm='backward' 约定下正变换不缩放，逆变换除以 N。Parseval 恒等式为 Σ|x_k|²=(1/N)Σ|X_j|²。周期边界是 DFT 的默认结构，不适合未经修改就套在零 Dirichlet 边界上。

\[
X_j=\sum_{k=0}^{N-1}x_k e^{-2\pi i jk/N},\quad x_k=\frac1N\sum_{j=0}^{N-1}X_j e^{2\pi i jk/N}
\]

图解的四个阶段：

1. **N 个样本 xₖ**——明确输入及必要的结构假设。

2. **单位圆根 ωʲ**——计算中间变换并保留变量的维度。

3. **复系数 Xⱼ**——把困难的高维关系拆成可控制的步骤。

4. **逆变换 / N**——通过残差、正交性或解析式核验结果。

## 一个可以手算的例子

对 N=4、x=(1,2,0,0)ᵀ，X₀=3，X₁=1−2i，X₂=−1，X₃=1+2i。频率 1 与频率 3 互为共轭，反映输入是实数。能量检查：时域 1²+2²=5；频域模方和为 9+5+1+5=20，再除以 N=4 正好得到 5。

## 适用条件以及会失败的地方

DFT 不是连续 Fourier 变换；样本的有限长度与周期延拓决定频谱解释。实信号满足共轭对称，但一般复信号不满足。归一化约定各软件不同：讲公式、比较能量与调用 API 时必须统一 norm。FFT 是计算 DFT 的快速算法，不是另一种数学变换。

## 总结：如何正确使用这个结论

DFT 是一个线性、可逆的坐标变换；频谱为什么有用，取决于原算子是否在 Fourier 基底下可分离或可对角化。
