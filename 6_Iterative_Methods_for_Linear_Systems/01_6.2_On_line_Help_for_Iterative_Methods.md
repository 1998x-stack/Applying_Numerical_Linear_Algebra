# 6.2 如何选择迭代求解器？

## 先描述问题，再搜索软件

一个求解器的名字不能告诉你它是否适合当前矩阵。选择之前，至少回答五个问题：

1. 系统是方阵 \(Ax=b\)，还是矩形最小二乘问题？
2. 矩阵是否对称（复数情形为 Hermitian）？
3. 是否正定？是否可能不定或奇异？
4. 矩阵是否稀疏？能否只提供 \(v\mapsto Av\) 的运算？
5. 需要多高的残差精度，能否构造有效预条件器？

这些信息决定可用算法的范围。错误地把一般矩阵交给 CG，不是“收敛慢一点”，而是违反了算法的数学前提。

## 经典在线帮助与现代软件文档

Demmel 原书第 6.2 节在 1997 年的语境下指向 NETLIB/templates：那里集中提供迭代方法的说明和代码。今天更实用的入口包括 SciPy 的 `scipy.sparse.linalg`、PETSc 等数值软件文档。无论使用哪个库，都应先阅读矩阵前提、停止条件、预条件器约定和返回状态，而不是只复制示例代码。

## 一个保守的选择表

| 问题结构 | 可优先评估的方法 | 必须确认的条件 |
|---|---|---|
| 对称正定方阵 | CG | \(A=A^T\)，且 \(x^TAx>0\)（非零 \(x\)） |
| 对称不定方阵 | MINRES | 对称性；并检查奇异情形和预条件器条件 |
| 一般非对称方阵 | GMRES、BiCGSTAB | 重启、预条件方向、真实残差和内存 |
| 矩形最小二乘问题 | LSQR、LSMR | 目标是最小化 \(\|Ax-b\|_2\)，而非解一个方阵系统 |
| 中等规模稀疏系统 | 稀疏直接法可作为基线 | 填充、排序、内存与因子复用成本 |

这张表是筛选入口，不是对所有矩阵都成立的速度排名。最终选择应使用真实数据和统一精度目标进行测量。

## 读取 API 时要核对什么？

以 SciPy 的 CG 接口为例：

- 文档明确要求 \(A\) 为对称/Hermitian 正定矩阵；
- 停止条件使用 \(\|b-Ax\|\leq\max(\text{rtol}\|b\|,\text{atol})\)；
- 返回的 `info=0` 表示达到容差，正值表示未在允许迭代数内达到容差；
- `M` 表示预条件器作用，理想上近似 \(A^{-1}\)，不应为了传参而显式计算矩阵逆。

GMRES 可处理一般方阵系统，但重启长度会影响内存和收敛；SciPy 文档还区分预条件残差与最终真实残差测试。接口参数和默认值会随版本变化，部署时应以所安装版本的官方文档为准。

## 可运行的结构化决策

本页 Python 函数只根据问题类型给出“值得评估的候选方法”，不会假装仅凭几个布尔值就能保证收敛或速度。交互控件可切换问题类型，查看候选算法和必要检查项。
